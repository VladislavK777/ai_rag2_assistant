# ER Diagram — модель данных

PostgreSQL (метаданные, RBAC, сессии, аудит, GraphRAG) + Qdrant (вектора) + MinIO (файлы).

## Обзор доменов

| Домен | Сущности |
|---|---|
| RBAC | `users`, `departments`, `roles`, `user_roles`, `permissions`, `workspaces` |
| Документы и RAG | `documents`, `chunks` (+ `qdrant_points` в Qdrant) |
| Диалоги | `sessions`, `messages` |
| STT | `stt_jobs` |
| GraphRAG | `graph_nodes`, `graph_edges` |
| Аудит | `audit_log` |

## Диаграмма

```mermaid
erDiagram
    users ||--o{ user_roles : ""
    roles ||--o{ user_roles : ""
    users ||--o{ permissions : "user-based"
    departments ||--o{ permissions : "dept-based"
    workspaces ||--o{ permissions : ""
    departments ||--o{ departments : "parent"
    departments ||--o{ users : ""
    users ||--o{ sessions : ""
    sessions ||--o{ messages : ""
    users ||--o{ audit_log : ""
    workspaces ||--o{ documents : ""
    documents ||--o{ chunks : ""
    chunks ||--|| qdrant_points : "point_id"
    documents ||--o{ stt_jobs : ""
    workspaces ||--o{ graph_nodes : ""
    graph_nodes ||--o{ graph_edges : "src"
    graph_nodes ||--o{ graph_edges : "dst"

    users {
        uuid id PK
        varchar email UK
        varchar full_name
        uuid department_id FK
        varchar password_hash
        boolean is_active
        timestamp created_at
    }

    departments {
        uuid id PK
        varchar name
        uuid parent_id FK "наследование прав"
    }

    roles {
        uuid id PK
        varchar name UK "admin, user, auditor"
    }

    user_roles {
        uuid user_id PK, FK
        uuid role_id PK, FK
    }

    permissions {
        uuid id PK
        uuid user_id FK "NULL если dept-based"
        uuid department_id FK "NULL если user-based"
        uuid workspace_id FK
        varchar level "read, write, admin"
    }

    workspaces {
        uuid id PK
        varchar name
        text description
        uuid owner_id FK
        timestamp created_at
    }

    documents {
        uuid id PK
        uuid workspace_id FK
        uuid uploaded_by FK
        varchar minio_key "файл в MinIO"
        varchar title
        varchar mime_type
        varchar status "pending, parsed, indexed, failed"
        timestamp created_at
    }

    chunks {
        uuid id PK
        uuid document_id FK
        varchar qdrant_point_id UK
        text content
        int chunk_index
        int token_count
        jsonb metadata "page, section, breadcrumb"
    }

    sessions {
        uuid id PK
        uuid user_id FK
        varchar title
        timestamp created_at
        timestamp updated_at
    }

    messages {
        uuid id PK
        uuid session_id FK
        varchar role "user, assistant, system"
        text content
        jsonb citations "chunk_id, document_id, title, page"
        int tokens_prompt
        int tokens_completion
        varchar trace_id
        timestamp created_at
    }

    stt_jobs {
        uuid id PK
        uuid document_id FK "NULL — аудио без документа"
        varchar audio_minio_key
        varchar status "queued, transcribing, summarizing, done, failed"
        text transcript
        text summary
        jsonb action_items
        float duration_sec
        timestamp created_at
    }

    graph_nodes {
        uuid id PK
        uuid workspace_id FK
        varchar name
        varchar node_type "person, project, contract, org"
        text description
    }

    graph_edges {
        uuid id PK
        uuid src_id FK
        uuid dst_id FK
        varchar relation "работает_над, участник, ссылается"
        float weight
    }

    audit_log {
        bigserial id PK
        timestamp ts
        uuid user_id FK "NULL для системных событий"
        varchar action "login, chat, doc_access, guardrail_block, export"
        varchar resource
        varchar decision "allow, deny"
        varchar trace_id
    }

    qdrant_points {
        varchar id PK "= chunks.qdrant_point_id"
        vector embedding "1024d BGE-M3"
        jsonb payload "acl_groups, acl_users, document_id, page"
    }
```

## Примечания

- `qdrant_points` — логическая сущность (реально хранится в Qdrant, показана для полноты).
- **RBAC-механика:** ACL пользователя = его `permissions` + права по иерархии `departments` → преобразуется в Qdrant payload-фильтр (`acl_groups ∈ dept_ids OR acl_users ∋ user_id`) → pre-filter до векторного поиска.
- `audit_log` — append-only: UPDATE/DELETE запрещены триггером, ретенция 1 год.
- `graph_nodes` / `graph_edges` — Knowledge Graph для GraphRAG, извлекается офлайн при ingestion; изоляция по `workspace_id`.
